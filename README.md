# ember_and_code_ducking_adventures
Ember & Code Ducking Adventures is a community-driven Jeep Ducking project where each duck has a unique identity, story, and adventure.
This repository contains:

The website frontend (HTML, CSS, JS)

The backend API for duck data, journeys, and achievements

The SQL Server database schema

Documentation for architecture, API design, and future development

The goal is to create a seamless experience where users can view ducks, track their adventures, and contribute new journey entries.
